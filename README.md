# Конфета — чат-менеджер

## Запуск

1. Установи Python 3.10+.
2. Установи зависимости командой `pip install -r requirements.txt`.
3. Скопируй `.env.example` в файл `.env`.
4. Вставь токен бота от `@BotFather` в `BOT_TOKEN`.
5. Запусти `python main.py`.

## Настройки Telegram

- Добавь бота в группы и выдай права администратора на блокировку пользователей и удаление сообщений.
- Чтобы бот видел обычные сообщения, отключи Privacy Mode через `@BotFather` → `/setprivacy` → Disable. Может понадобиться заново добавить бота в группу.
- Бот учитывает только группы, в которых он уже видел сообщения.
- Никому не передавай токен из `.env`.

## Команды

- `!помощь`
- `!id` — ответом на сообщение
- `+инспектор ID` / `-инспектор ID` — только владелец
- `+антиспам ID` / `-антиспам ID` — общая антиспам-база
- `!бан` — ответом на сообщение; причина на следующей строке; бан только в текущем чате
- `.конф ID`, `.конф @username` или `.конф` ответом на сообщение
- `!добавить 18+ https://t.me/addstickers/НазваниеНабора`
- `!список 18+`
- `!удалить 18+ https://t.me/addstickers/НазваниеНабора`

## Ограничения

- Поиск по `@username` работает, если бот уже видел этого пользователя и сохранил его username. Telegram Bot API не даёт надёжно получить ID любого произвольного username.
- Бот проверяет только стикеры из наборов, которые инспекторы добавили вручную; автоматического распознавания всех материалов 18+ нет.
- История начинается после установки этой версии. Старые события, которые бот не записывал, восстановить нельзя.
- В статистике банов учитываются баны, которые бот выполнил и записал. Ручные баны других администраторов ему неизвестны.
- Удаление из антиспам-базы не снимает уже выданные баны автоматически.
- Перед использованием проверь бота в тестовой группе.
